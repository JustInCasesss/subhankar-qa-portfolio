# Subhankar Patra — QA Portfolio

Personal portfolio for Subhankar Patra, QA Analyst. It keeps the supplied Astro template's layout and components, with the page content, project cards, and contact details personalized from Subhankar's resume.

## Run locally

```sh
pnpm install
pnpm dev
```

## Update portfolio content

- Edit profile, experience, skills, and contact details in `src/data/portfolio.ts`.
- Edit project case studies in `src/content/case-studies/`.
- Update project artwork in `public/images/qa-projects/`.
- Set `SITE_URL` in `.env` to the deployed site origin before publishing.

## Production build

```sh
pnpm build
pnpm preview
```
